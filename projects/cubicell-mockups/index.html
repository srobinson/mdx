CAMERA TIMELINE MOCKUPS

DIRECTION A · CAMERA TRACK AT CARD CRAFT LEVEL

fable-a

VIEW cards with live pose glyphs (orbit ring, azimuth dot, projection badge); MOVE cards carry path, easing, sweep. Two strips, one visual language.

grok-a

VIEW cards with captured-angle thumbnails; PATH cards (ORBIT / LINEAR / CUT) mirror the BUILD IN → STATE → TRANSITION rhythm.

opus-a

The camera has states too: a captured view is a State of the eye, the move between views is a Transition.

DIRECTION B · LEAN TIMELINE, INSPECTOR OWNS PROPERTIES

fable-b

Ruler, diamond keyframes, segment bars with orbit/linear/cut glyphs. Selection populates the Inspector, where properties already live app-wide.

grok-b

Camera collapses to a lean keyframe rail; selecting a keyframe or segment fills the inspector with pose path, easing, projection, sweep.

opus-b◆ OPUS SHIPS THIS

One rail edits everything: the state strip's own contract (cards are summaries, the right rail edits) extended to the camera track.

DIRECTION C · UNIFIED: TWO LANES, ONE INSTRUMENT

fable-c◆ FABLE SHIPS THIS

One ruler, one playhead, two lanes on real time, so a camera move visibly spans the states it films. Slim context bar defers to the inspector.

grok-c◆ GROK SHIPS THIS

STATE and CAMERA as peer lanes sharing scrubber, playhead, and craft language.

opus-c

Both timelines already describe the same 3.3 seconds, so they are drawn on one time axis.

V2 · ONE VISIBLE TIMELINE, CAMERA BOUND TO CARDS

fable-v2-1 · fable-v2-2

The camera ledge: a thin base ledge on every card where views and moves dock as chips; filmed, cut, latent, and bare all read from one line without touching the strip's grammar.

opus-v2-1

The camera ribbon: a 30px band along each card's bottom edge bleeding across gaps, so a filmed stretch reads as one lit ribbon; ‖ marks a hard cut, a dashed arc marks a sweep without captured endpoints.

opus-v2-2◆ OPUS SHIPS THIS

The possession tag: every card wears a view tag, solid when it owns a view, dashed inherit-mark when it rides the standing one; state thumbnails render from their bound view, ghosted when inherited.

V3 · THE PICK, REFINED

opus-v3◆ DIRECTION

Possession tags without a legend: words at position replace glyphs ("↻ 90° → V2", "CUT → V3" on the trailing edge); the ownership pair (lit+solid vs ghosted+dashed) is the only symbol left; one playhead-driven CAPTURE VIEW button; plain time cursor.
