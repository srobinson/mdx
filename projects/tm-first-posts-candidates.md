# First posts for @KnowMoreContext

Register: Tinkerer. Stance: veteran. Over a year of reading agent traffic on
the wire, and the account exists because the readings are worth publishing, not
because the looking is new. The instrument got sharper. The habit did not
change.

No discovery arc anywhere. No "I started", no first-look framing, no arriving at
an insight the reader watches land in real time. The numbers are today's and the
practice is old, and both of those facts are stated plainly.

Evidence used, exactly as verified on the wire on 2026-08-08:

- codex CLI request, user content 17 characters, developer payload 107,480
  characters, 64 MCP tool definitions injected by config, roughly 27k tokens of
  schemas on every request, `store=false`
- one claude request edited at the proxy, billed input 46,624 to 39,102 tokens,
  Anthropic's own usage numbers under `cache_creation`, 7,522 tokens on one
  exchange
- Claude Code 2.1.224 to 2.1.225 overnight, request shapes change with it

**Text, ready to paste:**

> 17 characters of user content. 107,480 characters in the developer block of the same codex request.
>
> 64 MCP tool definitions injected by config, roughly 27k tokens of schemas, present on every request in the session. store=false, so no copy exists to ask for afterwards. The accounting has to happen as the bytes leave.
>
> I have read agent traffic on the wire for over a year. The number is today's. The ratio is not.

**Attach:** the inspector screenshot showing the UNKNOWN 107k block beside the
17 character user turn. One tiny row against one enormous one, no caption
needed.

**Why it works cold:** the receipt is checkable in two seconds by a stranger
with their own codex config, and the last line sets the register for everything
that follows. It reports a measurement from a long-running practice, which is a
different posture from someone sharing a discovery, and that posture is what
makes a zero follower account worth reading.

## Candidate 3: long-form single post

**Text, ready to paste:**

> I read my agent traffic on the wire. Have done for over a year, long enough that the surprises are rare and the numbers are the point.
>
> A codex request today: user content 17 characters, developer block 107,480 characters. Almost all of that is tool schemas, 64 MCP tool definitions pulled in by config, roughly 27k tokens shipped on every request in the session. The request carried store=false, so the provider retains nothing anyone can go back and read. Whatever accounting exists has to happen at the moment the bytes leave.
>
> The weight has a price, which is the more useful half. I held one claude request at the proxy, trimmed boilerplate the harness injects, and released it. Billed input went from 46,624 tokens to 39,102. Anthropic's own usage numbers off the response, under cache_creation. 7,522 tokens on a single exchange, and the exchange still did its job.
>
> None of it holds still either. Claude Code shipped 2.1.224 and then 2.1.225 overnight, and the request shapes moved with it. A payload that a vendor rewrites while I sleep cannot be characterised once and filed away, which is why the instrument matters more than any single reading.
>
> Prompt engineering gets a lot of attention. On the wire the prompt is a small fraction of what is sent. I have a year of these readings. This is one of them.
>
> Token matters.

**Attach:** both inspector screenshots as a two image set, the 107k UNKNOWN
block first, the 46,624 to 39,102 token counts second. Reading order matches
paragraph order.

**Why it works cold:** it establishes authority in the first line and then
spends the rest of the post proving it with numbers rather than asserting it
again. "I have a year of these readings. This is one of them." tells a stranger
there is depth behind the account without promising a schedule or asking anyone
to wait for anything.

## Notes on selection

Candidate 3 is the opener. It is the only one that carries the full stance,
authority stated once and then demonstrated three times, and it reads as a
publication decision rather than an introduction.

Candidate 1 is the sharpest standalone and the most quotable, held for a
separate day since it spends the same 107,480 receipt.

Candidate 2 gets the most surface area per artifact but leans hardest on the
thread being read through, which is the weakest assumption at zero followers.
Its post 2 works as an independent post if the thread is dropped.
