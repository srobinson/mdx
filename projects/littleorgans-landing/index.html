Bounded contexts

The local system has a shape.

littleorgans keeps the operator model compact. Session owns intent. Runtime owns the host. Identity owns authorization. Transport observes the wire without taking control.

Session

Records, mail, nudges, labels, selectors, and the user verbs that turn intent into running work.

lilo get session

Runtime

Process launch, shim behavior, platform adapters, lifecycle events, capture, and raw status.

lilo runtime ...

Identity

The local service account and RBAC layer, applied inside session and runtime boundaries.

authorize, audit

Transport

Wire observation for agent traffic, captured turns, transcripts, and provider fidelity checks.

lilo transport ...

The rings are the model.

One operator at the center, surrounded by sessions, runtime state, mailbox evidence, and transport captures. Each ring is visible from the same command surface.

Step 1 Create

Start an agent as a session, not as an unmanaged terminal process.

Step 2 Observe

Read state, logs, mailbox activity, and captures without switching surfaces.

Step 3 Close

Wait for conditions, verify output, and retire the session cleanly.

Why it exists

Local agent work should be inspectable.

Coding agents are useful when their state is legible. littleorgans gives the operator a durable control plane for local sessions, not just another terminal convention.

Control
Session records before process mystery.

Managed work is created, listed, labeled, waited on, messaged, and deleted through `lilo`.

Runtime
Host execution stays explicit.

Raw runtime access remains diagnostic, gated, and separate from session backed user verbs.

Evidence
Observation is a first class path.

Transport captures the wire while session keeps the operator record and mailbox trail.

Install

Bring `lilo` onto the local machine.

The repo is pre release and operator focused. Build from source, check local health, then start using the command surface as the control plane for agent sessions.
