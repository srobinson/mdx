## Notes

- Source migration: docs.anthropic.com 301-redirects to platform.claude.com as of 2026-05-03. URLs in the table use the canonical (post-redirect) host. Both forms resolve to the same content. The original docs.anthropic.com URL is what most code samples and SDKs continue to reference, and the redirect preserves the `/docs/en/...` path.
- All sources are first-party Anthropic documentation. No secondary aggregators or practitioner writeups were used; the primary source covered every claim cleanly.
- The `cache_control` TTL values `"5m"` and `"1h"` are documented; intermediate values are not. The 1-hour option appears to be the only documented "extended" TTL.
- The maximum lookback window of 20 blocks per breakpoint is stated explicitly. This interacts with the 4-breakpoint maximum to produce the documented behavior where a growing conversation eventually pushes prior breakpoints out of the lookback window.
- The streaming docs note that "in accordance with the versioning policy, new event types may be added, and your code should handle unknown event types gracefully." So the catalog of events (`message_start`, `content_block_start`, `content_block_delta`, `content_block_stop`, `message_delta`, `message_stop`, `ping`, `error`) is exhaustive at the time of capture but may grow without a version bump.
- Delta sub-types observed in current docs: `text_delta`, `input_json_delta`, `thinking_delta`, `signature_delta`. The first two are the load-bearing ones for the essay; thinking and signature deltas only appear when extended thinking is enabled.
- Not pursued (out of scope for this brief): batches API, files API, MCP connector header semantics, beta headers (e.g., `anthropic-beta`), citations response shape, fine-grained tool streaming (`eager_input_streaming`). These are referenced in the docs but were not requested.
